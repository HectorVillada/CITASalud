# CITASalud
una solución web de auto agendamiento de citas médicas y exámenes de  diagnóstico, que permita a los usuarios adscritos a una EPS gestionar sus citas de forma  autónoma, eficiente y segura. Feature 1. Agendamiento de Citas Médicas Permite al usuario agendar, modificar y cancelar citas según disponibilidad médica y sede.
